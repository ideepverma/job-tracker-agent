
# Job Tracker Agent — 100% Free, Runs Locally

Monitors free job sources + your Gmail job-alert emails, filters for
Software Engineer / Backend Engineer / SDE / SWE Intern roles, logs
them to a local database, drafts cover letters, emails you a daily
digest, and reminds you to follow up 7 days after you apply.

**Cost: $0 forever.** No Airtable/Notion subscription, no OpenAI/Claude
API bill, no LinkedIn scraping (which would violate their ToS and get
you blocked). Everything runs on your own computer using free-tier
Google APIs and free public job feeds.

---

## 1. Install

```bash
cd job_tracker_agent
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Gmail Setup (one-time, ~5 minutes, free)

This lets the agent (a) read LinkedIn/Indeed "Job Alert" emails already
in your inbox and (b) send your daily digest.

1. Go to https://console.cloud.google.com/ and create a new project
   (any name, e.g. "job-tracker").
2. In the left menu: **APIs & Services → Library** → search **Gmail
   API** → click **Enable**.
3. **APIs & Services → OAuth consent screen**:
   - User type: **External**
   - Fill in app name (e.g. "Job Tracker Agent"), your email, save.
   - On the "Test users" step, add your own Gmail address.
4. **APIs & Services → Credentials → Create Credentials → OAuth client ID**:
   - Application type: **Desktop app**
   - Download the JSON → rename it `credentials.json` → place it in
     this `job_tracker_agent/` folder.
5. First time you run `python main.py`, a browser window will open
   asking you to log in and approve access. After that, a `token.json`
   is saved and reused automatically — you won't be asked again.

> This uses Google's free Gmail API quota (way more than a personal
> agent will ever use). No credit card, no billing account needed.

## 3. Turn on LinkedIn/Indeed Job Alerts in your inbox.

So the agent has alert emails to read:
- LinkedIn → Jobs → Job alerts → create alerts for "Software Engineer",
  "Backend Engineer", "SDE Intern", "SWE Intern" with **email
  notifications on**.
- Indeed → same idea via indeed.com/alerts.

## 4. Edit `config.yaml`

Set your email, keywords, exclusions, and fill in the `candidate:`
section (name, skills, achievement, education, portfolio) — this
powers the cover letter drafts.

## 5. Run it

```bash
python main.py
```

First run creates `data/jobs.db`, fetches jobs, and emails you a
digest. Each job in the digest has an expandable **draft cover
letter** and a `Job ID` you use to mark it applied:

```bash
python cli.py list                 # see everything tracked
python cli.py applied <job_id>     # starts the 7-day follow-up timer
python cli.py ignore <job_id>      # stop tracking a listing
python cli.py search "backend"     # search tracked jobs
```

## 6. Automate it to run daily (so you don't have to remember)

**Mac/Linux (cron):**
```bash
crontab -e
# add this line to run every day at 8:30am:
30 8 * * * cd /full/path/to/job_tracker_agent && /full/path/to/venv/bin/python main.py >> run.log 2>&1
```

**Windows (Task Scheduler):**
1. Open Task Scheduler → Create Basic Task
2. Trigger: Daily, pick a time
3. Action: Start a program →
   `C:\path\to\job_tracker_agent\venv\Scripts\python.exe`
   Arguments: `main.py`
   Start in: `C:\path\to\job_tracker_agent`

That's it — it'll run every day, log new matches, email your digest,
and send follow-up reminders automatically.

## Optional: smarter cover letters with a free local LLM

Install [Ollama](https://ollama.com) (free, runs entirely on your
machine) and pull a model:
```bash
ollama pull llama3.1
```
Then in `config.yaml` add:
```yaml
use_ollama: true
```
Cover letters will be generated by your local model instead of the
template — still $0, nothing sent to any paid API.

## Optional: also push jobs to Airtable or Notion

The core tracker uses local SQLite so it works with zero signups. If
you'd like a synced Airtable or Notion view later (both have free
tiers), that's a small add-on — ask and it can be wired in using their
free-tier REST APIs with your own API key.

## Notes & honest limitations

- LinkedIn does not offer a free scraping-safe job search API, so this
  agent does **not** scrape LinkedIn directly — it reads the job alert
  emails LinkedIn sends you instead, which is fully within their ToS.
- Cover letters are drafts to personalize and review before sending —
  always read them before submitting an application.
- Everything (job data, cover letters, your resume snippets) stays on
  your own machine in `data/jobs.db`.
